About Halkurd

Halkurd is a GNU/Linux distribution derived from Debian 12 (Bookworm). Its name originates from Halkurd Mountain — the highest peak in Iraq (3,607 m).

It is one of the first Iraqi GNU/Linux distributions — developed to address the scarcity of such projects in the country.

As the developer, I hope this distribution helps foster the spread of programming in my homeland.

Key Features

  • ✅ Based on Debian 12 (Bookworm) — stability and reliability
  • ✅ Lightweight Xfce desktop environment
  • ✅ Pre-configured for programming and daily use
  • ✅ Custom Halkurd branding, logo, and wallpapers
  • ✅ Calamares installer for easy installation
  • ✅ Bilingual support (English + Arabic)

New Features in v1.0.f

Halkurd v1.0.f introduces powerful new tools designed for stability, ease of use, and seamless updates.

🔄 Rolling Updates (Semi-Rolling Release)

Halkurd combines the legendary stability of Debian with the freshness of rolling releases. You can now update your system smoothly without reinstalling. Just open the terminal and type: halkurd-update to get the latest features and security patches.

🔔 Automatic Notifications

Stay informed! Halkurd now has a built-in notification daemon. It automatically checks for important announcements, security alerts, and new updates in the background (via halkurd-notify) and alerts you via your desktop.

🛠️ Advanced CLI Tools

We've built a full suite of terminal tools to make managing your system easier than ever:

  • halkurd-backup: Easily create compressed backups of your home directory and system configs.
  • halkurd-refresh: Quickly clean up unnecessary packages and refresh your apt sources.
  • halkurd-refreshsys: A powerful tool to fix broken dependencies and configure pending packages automatically.
  • halkurd-fetch: Show off your Halkurd system info with our custom terminal logo.
  • halkurd-update: update the system (rolling-like command).
  • halkurd-notify: Show all the System notifications from the developer كرم الباري.

Download & Boot

Requirements

  • 64-bit x86_64 CPU
  • 2 GB RAM minimum (4 GB recommended)
  • 20 GB free disk space
  • USB flash drive (4 GB+)

Steps to Boot

  1. Download the Halkurd ISO file (below).
  2. Write the ISO to a USB drive using balenaEtcher or dd.
  3. Reboot your computer and enter boot menu (F12 / F2 / Del).
  4. Select your USB device from the boot menu.
  5. Choose "Halkurd 1 - Live" from the menu.
  6. Test Halkurd in Live mode — your data is safe.
  7. Click "Install Halkurd" on the desktop to install.
# Write ISO to USB (Linux, replace /dev/sdX with your USB)
sudo dd if=Halkurd-1.iso of=/dev/sdX bs=4M status=progress conv=fsync
